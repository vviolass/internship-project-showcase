01 / GENERATIVE AI

Future Forcing

为未来帧，保留有价值的历史。

面向自回归视频生成的免训练 KV Cache 策略。以历史 pre-RoPE query 构造未来查询代理，对历史帧评分，在固定预算下淘汰与融合缓存。

PyTorchKV CacheRoPEVideo Generation
方法与验证边界

流程：clean-step query 统计 → 未来位置 RoPE → frame importance → eviction / merge。实验衡量相对 full-cache 输出的保真度，不能解释为真实视频质量。基于 Self Forcing 开源基座开展缓存策略实验。

02 / MEDICAL VISION

医学影像智能分析

视觉识别、报告生成与人工复核。

将染色体核型分析与胸片报告生成接入统一平台。Mask R-CNN + MViTv2 处理分割，ResNet50 完成分类，RGRG 生成区域描述与报告。

Detectron2FastAPIReactRGRG
系统设计与贡献边界

React → FastAPI → 核型推理 / HTTP RGRG Flask 服务。通过独立环境处理 Detectron2 与 RGRG 的依赖冲突。RGRG 为已有论文与开源模型；相关工作包括复现、部署、系统适配。

实验结果：原始图分割 AP 63.51 → 64.28；分类 TTA 99.10%（553 张测试图）。页面提供流程演示，不执行医学推理。

03 / ROBOTICS

ROS 智能无人艇

打通跨平台仿真与导航闭环。

连接 PE 三维引擎、ROS 与 MWORKS.Sysplorer，支持航线编辑、航迹跟踪、静态避障和状态同步。中国软件杯全国一等奖项目。

ROS1PythonVFHModelica
工程实现与贡献边界

主要工作包括 ROS 接入、调用链适配、VFH 避障改进和平台问题复现反馈；MWORKS 基础业务和导航来自赛题组参考代码。VFH 将 360° 分为 60 个扇区，基于安全半径膨胀障碍角区。

当前方案面向静态点障碍，未实现动态障碍预测。右侧及交互页为浏览器原理图，不连接 ROS 或原仿真平台。

04 / COMPILER

RISC · SysY 编译器

从源程序，到 RISC-V 汇编。

使用 Java 实现 SysY 编译流程，经过词法分析、语法分析、LLVM 风格 IR 与中端优化，最终进入 RISC-V 指令选择、寄存器分配和栈帧布局。

JavaSSA / CFGRISC-VCompiler
代码入口与验证边界

Compiler.java 串联 Lexer、Parser、符号表、Visitor、Optimizer 与 RiscvBuilder。前端分析、中端优化与 RISC-V 后端通过统一的中间表示衔接。
